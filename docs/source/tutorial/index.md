# Tutorials

Follow the first three tutorials in order. They use neutral lithium hydride
(LiH) to introduce the geometry, electron count, basis, grid, variational
algorithm and interpretation of a potential-energy curve.

```{toctree}
:maxdepth: 1

vqe_lih
adapt_vqe_lih
pes_scan
```

The additional tutorials cover smaller hydrogen examples, excited states and
periodic systems. They assume familiarity with the LiH workflow.

```{toctree}
:maxdepth: 1

vqe_h2
energy_levels
subspace_vqe
bloch_crystals
```
